Healthy Life Planner

A group project. It is an Arabic website that helps you organize your healthy day.

What it has
- Water tracker (click the cups)
- Daily habits list (add, finish, delete)
- Random healthy meal with a favorite button
- Contact form
- Dark and light mode


My part
I built the page structure with HTML and the design with CSS. I also worked on some simple JavaScript.

Built with
HTML, CSS, JavaScript


How to run
Download the files and open index.html in your browser.
